🔂 Full Priority Order (Execution Stack)  (Event Loop)

1. Synchronous code (Call Stack)
2. Microtasks:
   - Promise callbacks
   - async/await resolutions
   - queueMicrotask()
   - MutationObserver
3. Macrotasks:
   - setTimeout, setInterval
   - setImmediate (Node.js)
   - MessageChannel
   - UI events (click, input)
   - requestAnimationFrame (before next paint)
